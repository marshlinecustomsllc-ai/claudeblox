## FIXED (live puzzle feedback -- user-reported confusion)
- [x] Root cause investigation: user reported Echo Room's sequence buttons were confusing. Traced this to a systemic gap across ALL FIVE puzzle mechanics -- none of the physical interactive objects (lever needles, sequence panels, prism housings, pressure plates, sort gates) ever visually reflected their own live state. Every room relied entirely on the door opening as feedback, with zero moment-to-moment confirmation a press registered or was correct.
- [x] Built real-time visual feedback for all 5 mechanics: lever needles now physically rotate to show their value; prism housings now physically rotate to show their facing; sequence panels flash on every accepted press and strobe red room-wide on a wrong guess; pressure plates light up in their required color when correctly filled; sort gate indicators show ON/OFF state.
- [x] Code review found 2 SERIOUS bugs where the new feedback itself lied to the player: a Vault gate's indicator stayed green/"On" after the game silently reset it behind the scenes (every single orb, guaranteed); sequence panels permanently drifted toward red after repeated wrong presses due to a reversing-tween baseline bug (in a color-matching game, this corrupts the exact signal the puzzle depends on). Both fixed and verified live with real before/after property reads.
